🧠 How it works

  • Parses SQL into an AST using JSqlParser
  • Injects column = 'value' into the WHERE clause
  • 🛡️ Wraps OR expressions in parentheses to prevent leaks
  • Recursively modifies subqueries, JOINs, and UNIONs

⚡ Powered by real Java code running on Fly.io
